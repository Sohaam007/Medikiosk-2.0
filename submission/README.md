# Submission and Judging Materials

This directory contains only the final, redacted materials that a reviewer or
judge may need from the repository.

## Tracked

- `registration-kit.md` — registration copy and category information.
- `deck/SEVA-2026-Diploma-Higher-Education.pptx` — the tracked presentation.
- `evidence/` — only final, synthetic, redacted evidence that is intentionally
  small enough and safe to review in Git.

## Local-only and ignored

Use these directories for work-in-progress material; they are ignored by Git:

```text
submission/raw/   # raw captures, recordings, exports, and private working files
submission/work/  # draft decks, temporary renders, and review scratch files
```

Do not put PHI, credentials, private team records, unredacted screenshots, or
large recordings in the repository. Record a safe external artifact reference
and checksum in `docs/DEMO_EVIDENCE.md` when the final evidence is too large to
track.
