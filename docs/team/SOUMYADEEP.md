# Soumyadeep — Co-lead, Product Experience and Frontend

## Mission

Make the product understandable, accessible, reliable in a kiosk setting, and
convincing to patients, clinicians, judges, and partners without overstating
backend capabilities.

## Owns

- `frontend/` and the custom MediKiosk visual system.
- Kiosk and clinician workflows.
- Landing page and product narrative.
- Generated OpenAPI client consumption.
- Accessibility, touch targets, responsive behavior, and browser fallbacks.
- Demo screenshots and visual acceptance with Pabitra.

## Must review

- API/client contract changes with Soham.
- Clinical wording and screening disclaimers.
- Offline/error/loading states.
- Any UI that implies live integration, booking, payment, or diagnosis.

## SEVA deliverables

- Stable five-minute kiosk-to-clinician demo.
- Visible mock/offline/local-model labels.
- CardioVision explanation panel with safe fallback.
- Landing/pitch surface describing the complete journey while clearly separating
  the current prototype from the future product.

## Stop conditions

Stop when a UI needs a new API shape not approved by Soham, when a fallback could
look like provider success, or when a large view change lacks a regression path.
