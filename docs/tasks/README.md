# Historical Task Material

The Markdown files in this directory are historical planning/task material from
earlier waves. They are useful for intent and acceptance ideas, but they are not
the active backlog and may mention paths that no longer exist.

Before implementing anything from a task file:

1. verify the active path in `docs/ARCHITECTURE.md`;
2. verify current status in `docs/STATUS.md`;
3. reconcile the task against current contracts and tests;
4. create a bounded task packet using `docs/templates/FEATURE.md`;
5. add/update an ADR when the task changes a contract or boundary.

Do not automatically select the first `Status: todo` item in this directory.
