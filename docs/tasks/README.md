# Task Packets

Current work belongs under `docs/tasks/active/` and is indexed by
`docs/FEATURES.md`.

Historical task material from earlier waves is kept outside the repository in a
local-only archive when it is needed for local research. It is not an active
backlog, is not available in a clean clone, and must never be selected
automatically by an agent.

Before implementing any historical idea, verify the active architecture,
contracts, tests, and status, then create a new bounded packet from
`docs/templates/FEATURE.md`.
